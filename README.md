# chrono

A simple time-tracking and timesheet plugin for JetBrains IDEs.

Chrono lets you track the time you spend working on projects directly from your IDE, without leaving your development workflow.

## Features

* Start and stop time tracking
* Track time spent on projects
* Manage your current work session
* View recorded time
* Lightweight
* Designed for JetBrains IDEs


## Usage

After installation, Chrono is available directly inside your JetBrains IDE (in StatusBar at the right)

Start a timer when you begin working and stop it when you finish.
The records are stored daily in csv format at "$HOME/.jetbrains-chorno"

## Supported IDEs

Chrono is built for JetBrains IDEs and supports modern IntelliJ Platform versions.
